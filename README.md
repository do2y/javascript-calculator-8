# 🧮 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기
<br><br>

## 구현 기능 목록

- [x] **사용자 입력 처리**

  - [x] 사용자로부터 계산할 문자열을 입력받는다.

- [x] **문자열 파싱 및 숫자 추출**

  - [x] 문자열에 쉼표 `,` 또는 콜론 `:`이 포함된 경우, 해당 구분자를 기준으로 분리한다.
  - [x] 문자열 앞부분에 `//`와 `\n` 사이의 문자가 존재할 경우, 이를 커스텀 구분자로 인식하여 분리한다.
  - [x] 분리된 값을 숫자 배열로 변환한다.

- [x] **합산**

  - [x] 추출한 숫자들을 모두 더해 합산한다.
  - [x] 입력이 빈 문자열(`""`)일 경우 결과로 0을 반환한다.

- [x] **예외 처리**
  - [x] 잘못된 값을 입력한 경우 `[ERROR]`로 시작하는 메시지와 함께 `Error`를 발생시키고 프로그램을 종료한다.

<br>

## 예외

- [x] **잘못된 문자 입력**

  - [x] 쉼표, 콜론, 커스텀 구분자 외의 문자가 포함된 경우
  - [x] ex) `"1,a:3"`, `"//;\n1;2;x"`
    - [ERROR] 입력은 숫자와 지정된 구분자(, : 또는 커스텀 구분자)만 가능합니다.

- [x] **음수 입력**

  - [x] 구분자로 분리한 값 중 하나라도 음수인 경우
  - [x] ex) `"1,-2,3"`
    - [ERROR] 음수는 입력할 수 없습니다.

- [x] **유효한 숫자 없이 구분자만 입력된 경우**

  - [x] ex) `","`, `":"`
    - [ERROR] 숫자가 포함되어야 합니다.

- [x] **구분자가 문자열의 앞뒤에 위치한 경우**

  - [x] ex) `",123"`, `"343,1,"`
    - [ERROR] 구분자는 문자열의 앞이나 뒤에 위치할 수 없습니다.

- [x] **잘못된 커스텀 구분자 입력**

  - [x] 커스텀 구분자는 `//`와 `\n` 사이의 한 문자만 허용한다.
    - [ERROR] 커스텀 구분자는 한 글자만 가능합니다.
  - [x] `//` 뒤에 구분자가 없이 바로 `\n`이 오는 경우 예외로 처리한다.
    - [ERROR] 커스텀 구분자가 입력되지 않았습니다.
  - [x] `//`로 시작했지만 `\n`이 존재하지 않는 경우도 형식 오류로 본다.
    - [ERROR] 잘못된 커스텀 구분자 형식입니다.
  - [x] 커스텀 구분자는 숫자가 될 수 없다.
    - [ERROR] 커스텀 구분자로 숫자는 사용할 수 없습니다.
  - [x] ex) `"//;#\n1;2#3"`, `"//\n1,2,3"`, `"//1;2;3"`, `"//1\n21231"`

- [x] **기타 파싱 불가능한 입력 전체**

  - [x] ex) `"abc"`
    - [ERROR] 입력은 숫자와 지정된 구분자(, : 또는 커스텀 구분자)만 가능합니다.

<br>

## 추가 구현 사항

- 입력 문자열 내 공백 허용

  - 숫자와 구분자 사이에 공백이 포함되어도 정상적으로 처리되도록 구현함.
  - ex) "1, 2 : 3" → 결과 : 6

- 커스텀 구분자는 한 문자만 허용

  - 여러 문자를 허용할 경우,
    //123,123\n123,123처럼 의도치 않은 문자열이 커스텀 구분자로 인식될 위험이 있어
    입력 해석의 일관성과 안정성을 위해 한 문자만 인식하도록 설계함.
  - ex) "//;\n1;2;3" → 정상 처리
  - ex) "//;;\n1;;2" → [ERROR] 커스텀 구분자는 한 글자만 가능합니다.

- 커스텀 구분자로 숫자 불가

  - 숫자를 구분자로 지정할 경우 입력 파싱의 혼란이 발생할 수 있으므로
    //1\n21231과 같은 입력은 오류로 처리함.
  - [ERROR] 커스텀 구분자로 숫자는 사용할 수 없습니다.
