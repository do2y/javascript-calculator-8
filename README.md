# 🧮 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기
<br><br>

## 구현 기능 목록

- [x] **사용자 입력 처리**
  - [x] 사용자로부터 계산할 문자열을 입력받는다.

- [ ] **문자열 파싱 및 숫자 추출**
  - [ ] 문자열에 쉼표 `,` 또는 콜론 `:`이 포함된 경우, 해당 구분자를 기준으로 분리한다.
  - [ ] 문자열 앞부분에 `//`와 `\n` 사이의 문자가 존재할 경우, 이를 커스텀 구분자로 인식하여 분리한다.
  - [ ] 분리된 값을 숫자 배열로 변환한다.

- [ ] **합산**
  - [ ] 추출한 숫자들을 모두 더해 합산한다.
  - [ ] 입력이 빈 문자열(`""`)일 경우 결과로 0을 반환한다.

- [ ] **예외 처리**
  - [ ] 잘못된 값을 입력한 경우 `[ERROR]`로 시작하는 메시지와 함께 `Error`를 발생시키고 프로그램을 종료한다.

<br>

## 예외

- [ ] **잘못된 문자 입력**
  - [ ] 쉼표, 콜론, 커스텀 구분자 외의 문자가 포함된 경우
  - [ ] ex) `"1,a:3"`, `"//;\n1;2;x"`

- [ ] **음수 입력**
  - [ ] 구분자로 분리한 값 중 하나라도 음수인 경우
  - [ ] ex) `"1,-2,3"`

- [ ] **유효한 숫자 없이 구분자만 입력된 경우**
  - [ ] ex) `","`, `":"`, `"//;\n;;"`

- [ ] **구분자가 문자열의 앞뒤에 위치한 경우**
  - [ ] ex) `",123"`, `"343,1,"`

- [ ] **기타 파싱 불가능한 입력 전체**
  - [ ] ex) `"abc"`
